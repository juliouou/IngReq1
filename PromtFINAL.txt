3. Con toda la documentación previamente cargada, la arquitectura aprobada y la propuesta UX/UI aprobada:

Genera ahora el prototipo vertical completo de SAMR.

IMPORTANTE — CALIDAD VISUAL Y EXPERIENCIA DE USUARIO

El prototipo NO debe parecer una maqueta académica básica ni una colección de formularios simples.

Debe verse como una plataforma médica profesional moderna lista para demostración con stakeholders reales.

Aplica principios de:

* WCAG 2.1 Nivel AA
* Diseño Centrado en el Usuario (UCD)
* Mobile First
* Responsive Design
* Design System consistente
* Heurísticas de Nielsen
* Arquitectura de Información clara
* Jerarquía Visual moderna

La interfaz debe incluir:

* Dashboard profesional con métricas visuales
* Tarjetas informativas (cards)
* Navegación lateral persistente
* Barra superior contextual
* Estados visuales claros
* Indicadores de riesgo mediante componentes visuales
* Tablas modernas
* Formularios profesionales
* Modales consistentes
* Alertas visuales
* Componentes reutilizables

El diseño visual debe transmitir:

* Confianza
* Profesionalismo médico
* Innovación tecnológica
* Accesibilidad
* Claridad

Evita:

* Formularios HTML básicos
* Interfaces desordenadas
* Pantallas vacías
* Elementos sin alineación
* Botones genéricos sin diseño
* Uso excesivo de texto

Utiliza un sistema visual coherente con:

* Colores institucionales del sector salud
* Espaciado consistente
* Tipografía moderna
* Componentes reutilizables
* Diseño tipo dashboard SaaS empresarial
